## 🟦 [1차 과제: V1.0] 기초 뼈대 구축 (입출력과 변수)
### **✨V1.0 개발 내용:**
  * 변수설계: 국가코드(char),인원/총액(int),환율/결과값(double)등 총 6개의 의미 있는  변수를 사용하였습니다.
  * 기능 구현: printf 와 scanf 를 통한 사용자 상호작용 및 *,/ 연산자를 이용한 경비 계산 기능을 구현하였습니다.
  * 논리 구조: 제어문(if,for) 없이 위에서 아래로 흐르는 순차구조로 설게하여 과제 제약 사항을 완벽하게 준수하였습니다.
    
### **🤖 AI 파트너십 과정**\
과제 조건에 최적화된 '여행 경비 정산'이란느 아이디어를 AI와 함께 선정하였습니다.
설계 협력 : 제어문 없이 논리적 흐름을 구성하는법과 int , double자료형 혼합시 데이터 유실을막는 수식을 자문받았습니다.
디버깅 및 검수: scanf의 %lf 포맷팅 오류 방지 및 명시적 형변환을 통한 계산 정밀도 향상 과정을 거쳐 최종 코드를 완성하였습니다.

    
### **🛠️ Troubleshooting & 기술 회고:**
현상: individualLocal 계산시 소수점이 무시되고 정수값만 나오는 현상이 발생하였습니다.
원인: int/int 연산은 결과값이 자동으로 int 가 되기때문입니다.
해결: (double) totalExpense /totalPeople과 같이 분자를 실수형으로 강제 변환하여 소수점 이하 자리까지 정확히 계산되도록 수정하였습니다.

  * 인원수가 정상인지 확인하는 1차 조건문 내부에 5인 이상이면서 총지출액이1000 이상이라는 2가지 조건을 동시에 만족할때 5% 단체할인을 적용하는 2차 조건문을 중첩하여 구현했습니다.

## 🟨 [3차 과제: V3.0] 무한 루프와 메뉴 시스템 (반복문) - 향후 작성 예정
### **✨3차 과제 업데이트 내용:**
  * 무한 반복문 while(1)을 활용하여 사용자가 프로그램을 종료하기 전까지 메뉴를 계속 반복해서 출력되도록 시스템을 개편했습니다.
  변수명 최적화: 타이핑 편의성과 코드 간결성을 위해 기존의 긴 영어 변수명들을 이니셜화하여 주석으로 의미를 명시하였습니다.
  메뉴 분기 시스템을 구축하여 사용자의 입력값(1:정산기 실행,0:프로그램종료 )에 따라 기능이 나뉘도록 구현했습니다.
  break문을 전력적으로 배치하여 예외 상황 발생시 메뉴로 복귀하거나 0입력시 무한 루프를 완전히 탈출하여 프로그램을 종료하도록 제어했습니다.

    
### **🤖 AI 파트너십 과정**
 1. **내용 1**
 2. 반복문(while(1)),값 매칭 분기(switch~ case), 반복 제어(break)를 활용하여 0 입력 시 종료되는 메뉴 화면 구현 요청시킨다. 
     **적용 내용:** ....
     기존 2차 과제 코드의 겉을 while(1)로 감싸고 입력받은 메뉴 번호에 따라 기능이 실행되도록 기본 골격을 구축했습니다.
    * **프롬프트 요약:** 
    * 긴 영어 변수명들을 이니셜로 줄여달라고 요청
    
     **적용 내용:** 
     destinationCode 를 dc로 변경하는 등 모든 변수를 짧은 이니셜로 수정하고 선언부에 원래 이름을 주석으로 달아 나중에도 알아보기 쉽도록 다듬었다.

### **🛠️ Troubleshooting & 기술 회고:**
  1. **문제 1:** ...
   2차 과제 버전에서는 잘못괸 지역코드나 인원수를 입력하면 return 0;를 사용하여 프로그램이 아예 꺼지도록 설정되어 있었다.
   메뉴 시스템에서는 에러가 나더라도 다시 메뉴로 돌아가야 한다.
* **해결:** ...
   에러 처리구문의 return 0;을 break;로 수정했다.
  이를 통해 에러 발생시 프로그램이 종료되지 않고 switch 구문만 빠져나간뒤 다시 while(0)의 처음으로 돌아가 메인 메뉴를 정상적으로 띄울 수 있게 되었다.

문제 2:** 
    0번을 눌러 프로그램을 종료하려 할때 switch 문안에서 break를 호출하면 switch 조건문만 빠져나올 뿐 while(1)무한 루프는 탈출 하지 못하였다.
  
   **해결:** ...
    switch 블록 바깥 while 루프 끝부분에 if(mc == 0){break}구문을 추가로 배치했습니다.
    사용자가 0을 누르면 switch를 빠져나온 후 이조건문을 만나 무한 루프 자체를 안전하게 탈출하여 프로그램을 완전히 종료되도록 이중 탈출 구조를 설계했다.
